# AstraClient

AstraClient is an independent Windows launcher for Minecraft: Java Edition.

## Public site

The GitHub Pages site is in [`docs/`](docs/). Enable **Settings → Pages** and publish the `main` branch from the `/docs` folder.

Expected public URLs for the `poteuxx/AstraClient` repository:

- https://poteuxx.github.io/AstraClient/
- https://poteuxx.github.io/AstraClient/privacy.html
- https://poteuxx.github.io/AstraClient/terms.html
